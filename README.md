## 第一阶段：6月（打基础） {#6月}

### 1️⃣ Python 基础（第1-2周）

**学习内容**
- 基础语法：变量、数据类型、控制流
- 函数与面向对象编程
- 文件操作、异常处理

**学习资源**
- Python 官方文档
- 《Python Cookbook》
- Jupyter Notebook 实践

**时间投入：** 10-14 天

### 2️⃣ 数据处理核心库（第2-4周）

这是最重要的部分！必须掌握**三大库**：

##### **NumPy - 数值计算**
```
# 主要概念
- 数组操作（创建、索引、切片）
- 矩阵运算（加减乘除、转置）
- 统计函数（mean、std、var）
- 随机数生成

学习时间：3-4 天
```

##### **Pandas - 数据处理**（重点！）
```
# 核心对象与操作
- Series 与 DataFrame
- 数据读写（CSV、Excel、SQL）
- 数据清洗（缺失值、重复值处理）
- 数据变换（merge、concat、pivot_table）
- 数据聚合（groupby、agg）

学习时间：1 周
```

##### **Matplotlib/Seaborn - 数据可视化**
```
# 可视化类型
- 折线图、柱状图、散点图
- 箱线图、热力图
- 多子图布局
- 自定义样式与配置

学习时间：3-4 天
```

**学习资源**
- 官方文档（pandas.pydata.org）
- Kaggle Learn 免费课程
- 实战练习：30+ 小项目

**检查清单**
- [ ] 掌握 NumPy 数组操作
- [ ] 熟练使用 Pandas DataFrame
- [ ] 能绘制多种类型的图表
- [ ] 完成 30+ 个数据处理练习

### 📊 第二阶段：7月（项目1 + 继续刷题）

#### 📈 项目1：电商数据分析平台

**项目目标**
- 展示 Pandas、SQL、可视化能力
- 理解数据分析的完整流程
- 准备秋招面试的谈资

**技术栈**
```
数据层：MySQL 数据库
    ↓
业务层：Python Pandas 处理
    ↓
分析层：数据分析、建模
    ↓
展示层：FastAPI + 前端/可视化工具
```

**核心功能模块**

##### 1. 用户分析模块
```python
- 用户活跃度分析
  * 日活、月活统计
  * 活跃时段分析
  * 用户留存率计算

- 用户分群
  * RFM 模型分析
  * 用户分类（高价值、普通、流失）

- 用户行为分析
  * 购买路径分析
  * 页面访问分析
```

##### 2. 销售分析模块
```python
- 销售概览
  * 总销售额、订单数
  * 日均销售额
  * 销售趋势

- 产品分析
  * 热销产品排行
  * 产品类别贡献度
  * 产品生命周期分析

- 转化率分析
  * 漏斗分析
  * 转化率按时间/渠道分解
```

##### 3. 数据可视化模块
```python
- 仪表板设计
  * 实时数据展示
  * KPI 关键指标

- 报告生成
  * 自动生成 PDF 报告
  * 数据对比分析图表
```

**项目架构**
```
project/
├── data/                    # 原始数据
│   └── sales_data.csv
├── notebooks/              # Jupyter 分析笔记
│   ├── 01_data_cleaning.ipynb
│   ├── 02_user_analysis.ipynb
│   └── 03_sales_analysis.ipynb
├── src/                    # Python 源代码
│   ├── data_loader.py      # 数据加载
│   ├── data_cleaner.py     # 数据清洗
│   ├── analyzer.py         # 数据分析
│   └── visualizer.py       # 可视化
├── api/                    # FastAPI 应用
│   └── main.py
├── output/                 # 输出报告
│   └── report.pdf
├── README.md               # 项目说明
└── requirements.txt        # 依赖
```
